# A. Maximize One MEX

time limit per test: 1 second

memory limit per test: 256 megabytes

input: standard input

output: standard output

Given an array $a$ of length $n$, which is a permutation of the integers $0,1,\ldots,n-1$, you can perform the following operation **at most** once:

-   Choose two distinct indices $i$ and $j$ ($i \ne j$), and swap the values of $a_i$ and $a_j$.

After performing the operation, define $f_i=\operatorname{mex}(a_1, a_2, \ldots, a_i)$. $\operatorname{mex}(c)$ denotes the minimum excluded (MEX)$^{\text{∗}}$ of the collection $c$.

Given an integer $k$, find two indices to use in the operation above so as to maximize the $k$\-th largest value among $f_1, f_2, \ldots, f_n$. If no operation is needed, output $-1$.

If there are several valid answers, you may output any of them.

$^{\text{∗}}$The minimum excluded (MEX) of a collection of integers $c_1, c_2, \ldots, c_k$ is defined as the smallest non-negative integer $x$ which does not occur in the collection $c$.

#### **Input**

Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 50$). The description of the test cases follows.

For each test case, the first line contains two integers $n$ and $k$ ($2 \le n \le 100$, $1 \le k \le n$), where $n$ is the number of elements in the array $a$ and $k$ is the rank of the value to be maximized (with $k=1$ corresponding to the largest value).

The next line contains $n$ integers: $a_1,a_2,\ldots,a_n$. It is guaranteed that each of the values $0,1,\ldots,n−1$ appears exactly once in the array $a$.

It is guaranteed that the sum of $n$ over all test cases does not exceed $100$.

#### **Output**

For each test case, output a single line that contains two indices used in the operation to maximize the $k$\-th largest value among $f_1, f_2, \ldots, f_n$. If no operation is needed, output $-1$.

#### **Example**

Input

```
3
5 1
0 1 2 3 4
3 2
2 0 1
5 2
0 2 1 4 3
```

Output

```
-1
1 3
4 5
```

#### **Note**

In the first test case, no operation is needed; the $1$st largest value among $f_1, f_2, \ldots, f_5$ is $f_5=5$. Actually, if we perform the swap operation, no matter which two indices we choose, $f_5$ is always the largest one, with value $5$.

In the second test case, after swapping $a_1$ and $a_3$, we get the array $[1,0,2]$, and $f_1=0, f_2=2, f_3=3$; the $2$nd largest value among $f_1, f_2, f_3$ is $f_2=2$.



## Sol

显然 $f_i > f_{i-1}$，所以第 $k$ 大的 $f$ 就是 $f_{n-k+1}$，那么只关注前 $n-k+1$ 个数即可。

若前 $n-k+1$ 个数正好是 $0 \sim n - k$，那么无法通过交换来提升 $f_{n-k+1}$；

否则，应该把 $f_{n-k+1}$ 交换到前半段来，把谁换走呢？考虑：前半段是 $0,1,2,4,5,6$，应该换一个 $3$ 过来，把 $6$ 换走，即换走最大的数字。

特别地，当 $k = 1$ 时，答案直接是 $n$。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, k, a[105], pos[105];
bool v[105];
void solve() {
    memset(v, 0, sizeof v);
    cin >> n >> k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pos[a[i]] = i;
        if (i <= n - k + 1) v[a[i]] = 1;
    }
    for (int i = 0; i <= n; i++) {
        if (!v[i]) {
            if (i == n - k + 1) {
                cout << -1 << endl;
                return;
            }
            int max_pos = 0;
            for (int j = 1; j <= n - k + 1; j++) {
                if (a[j] > a[max_pos]) {
                    max_pos = j;
                }
            }
            cout << max_pos << " " << pos[i] << endl;
            return;
        }
    }

}
int main() {
    int t;
    cin >> t;
    while (t --) solve();
	return 0;
}
```

# B. Frogs Jump

time limit per test: 1 second

memory limit per test: 256 megabytes

input: standard input

output: standard output

Given a $2 \times n$ grid, each cell of the grid is either empty or contains one frog. It is guaranteed that **each column** of the input grid contains **at least one** frog. You can choose $k$ frogs and remove them from the grid. After this, all remaining frogs will jump.

Each frog can jump up, down, left, or right by $1$ cell, but cannot jump outside the grid. All frogs must choose a legal direction and jump simultaneously exactly once. After jumping, the number of frogs in each row and each column of the grid must remain unchanged.

Note that:

-   Even if two frogs' jump directions conflict, they can still jump to their respective target cells.
-   Multiple frogs are allowed to jump to the same cell, because a cell can hold arbitrarily many frogs.

Find the minimum $k$ such that there exists a valid jumping scheme.

#### **Input**

Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 10^4$). The description of the test cases follows.

For each test case, the first line contains a single integer $n$ ($1 \le n \le 2 \cdot 10^5$), where $n$ is the number of columns in the grid.

The next two lines each contain a string of length $n$; we use the character $\texttt{f}$ to represent a cell containing a frog, and the character $\texttt{o}$ to represent an empty cell.

It is guaranteed that **each column** of the input grid contains **at least one** frog.

It is guaranteed that the sum of $n$ over all test cases does not exceed $2 \cdot 10^5$.

#### **Output**

For each test case, output a single line containing the minimum $k$ such that there exists a valid jumping scheme.

**Example**

Input

```
4
2
ff
oo
2
fo
of
3
fof
ofo
1
f
o
```

Output

```
0
0
1
1
```

#### **Note**

In the first test case, two frogs can jump to each other's cells.

In the second test case, the left frog can jump down, and the right frog can jump up. After the jumps, the total number of frogs in each row and each column remains $1$.

| o    | f    |
| ---- | ---- |
| f    | o    |

In the third test case, three frogs can all jump to the same cell $(1,2)$, although it is not a valid answer, since the number of frogs in the first column changes from $1$ to $0$.

| o    | f f f | o    |
| ---- | ----- | ---- |
| o    | o     | o    |



## Sol

答案就是 $cnt \bmod 2$。

结论：存在一种合法跳跃方案，当且仅当青蛙的数量为偶数。

充分性证明：

青蛙分成两类：A类是向左右跳跃的，B类是上下跳跃的。

设第 $i$ 列有 $c_i$ 只A类青蛙，分别有 $l_i,r_i$ 只青蛙向左、右跳跃，则 $c_i = l_i + r_i$，为了保持这列数量不变，需要满足 $r_i = l_{i+1}, l_1 = r_n = l_{n+1} = 0$，现在把所有列A类青蛙数量求和：
$$
\sum\limits_{i=1}^n c_i = \sum\limits_{i=1}^n l_i + r_i = \sum\limits_{i=1}^n l_i + l_{i+1} = l_1 + l_{n+1} + 2\sum\limits_{i=2}^n = 2\sum\limits_{i=2}^n
$$
为偶数。

对于B类青蛙，它们向上跳的青蛙数量必然等于向下跳的，总量也是偶数。

必要性证明：

现在考虑如果青蛙数量是偶数，如何构造出合法跳跃方案：

从左到右维护一个值 $cur\in\{0,1\}$，初始 $cur=0$。

- 当前列只有 1 只青蛙：
  - $cur=0$：让它向右跳，令 $cur=1$；
  - $cur=1$：让它向左跳，令 $cur=0$。
- 当前列有 2 只青蛙：
  - $cur=0$：两只都竖直跳，交换两行，$cur$ 仍为 0；
  - $cur=1$：两只都水平跳，一只向左、一只向右，$cur$ 仍为 1。

每个单青蛙列会翻转 $cur$，每个双青蛙列不改变 $cur$。

因为青蛙总数为偶数，而双青蛙列贡献偶数只青蛙，所以单青蛙列数量为偶数，最终 $cur=0$。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int t;
    cin >> t;
    while (t --) {
        int n;
        cin >> n;
        int f = 0;
        string s;
        cin >> s;
        for (char &c : s) f += c == 'f';
        cin >> s;
        for (char &c : s) f += c == 'f';
        cout << f % 2 << endl;
    }
	return 0;
}
```

# C. Yet Another Black Cell Problem

time limit per test: 2 seconds

memory limit per test: 256 megabytes

input: standard input

output: standard output

*Inspired by [this problem](https://codeforces.com/contest/2026/problem/B).*

There is a strip divided into cells numbered from $0$ to $10^9$ from left to right. Initially, all cells are white.

An array $a$ of length $n$ is given, containing the indices of $n$ cells. We want to paint all these $n$ cells black.

Given an integer $x$, you may choose an integer $y$ such that $0 \le y \le x$, and then arbitrarily select $y$ cells that are **not in** $a$. We also want to paint these selected $y$ cells black while keeping all non-selected cells white.

You may perform the following operation any number of times:

-   Choose two distinct cells $i$ and $j$ such that $1 \le |i-j| \le k$, and paint them black, regardless of whether they were originally black or white.

Find the minimum value of $k$ for which it is possible to paint all the required cells black while keeping other cells white.

#### **Input**

Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 10^4$). The description of the test cases follows.

The first line of each test case contains two integers $n$ and $x$ ($2\leq n\leq 2\cdot 10^5,0\leq x\leq n$).

The second line contains $n$ integers $a_1,a_2,\ldots,a_n$ ($0\leq a_i\leq 10^{9}$). It is guaranteed that $a_i \lt a_{i+1}$ for all $1 \leq i \lt n$.

It is guaranteed that the sum of $n$ over all test cases does not exceed $2\cdot 10^5$.

#### **Output**

For each test case, print a single integer — the minimum value of $k$ for which it is possible to paint all the required cells black while keeping other cells white.

#### **Example**

Input

```
4
2 0
1 3
2 1
1 3
3 1
2 5 7
10 2
0 6 8 10 13 14 16 19 25 31
```

Output

```
2
1
2
3
```

#### **Note**

In the first example, we cannot paint any cell other than $1$ and $3$ black because $x=0$. So it's optimal to set $k=2$ and choose $i=1,j=3$ in the first operation.

In the second example, we can set $k=1$, which is the minimal available value. We first choose $i=1,j=2$ to paint and then choose $i=2,j=3$ to paint. After that, cells $1,2,3$ are painted black, only cell $2$ is not in the given list, which satisfies the condition $x=1$.



## Sol

有明显单调性：若 $k$ 可行，那么 $>k$ 的结果都可行，反之亦然，考虑二分 $k$。

check函数中，先看哪些点之间的距离本就是 $\leq k$ 的，忽略它们，再考虑其他的孤点。

从左到右考虑两个相邻孤点，若它们的间距 $\leq 2k$，可以通过再它们之间染一个点的形式，把这两个孤点都处理了，即付出一点代价处理两个点；否则只能付出一点代价处理一个点。判断代价是否 $\leq x$。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 2e5 + 5;
int n, x, a[N];
int b[N], tot;
bool check(int k) {
    tot = 0;
    if (a[2] - a[1] > k) b[++ tot] = 1;
    for (int i = 2; i < n; i++) {
        if (a[i + 1] - a[i] > k && a[i - 1] - a[i] < k) {
            b[++ tot] = i;
        }
    }
    if (a[n] - a[n - 1] > k) b[++ tot] = n;
    int cnt = 0;
    for (int i = 1; i <= tot; i++) {
        if (i < tot && a[i + 1] - a[i] <= 2 * k) {
            cnt ++;
            i ++;
        } else {
            cnt ++;
        }
    }
    return cnt <= x;
}
void solve() {
    cin >> n >> x;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int l = 1, r = 1e9, ans;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (check(mid)) r = mid - 1, ans = mid;
        else l = mid + 1;
    }
    cout << ans << endl;
}
int main() {
    int t;
    cin >> t;
    while (t --) solve();
	return 0;
}
```



# D. Connecting the Conflicts

time limit per test: 2 seconds

memory limit per test: 256 megabytes

input: standard input

output: standard output

A tree is a connected graph without cycles. Define an [independent set](https://en.wikipedia.org/wiki/Independent_set_\(graph_theory\)) of a tree as a set of vertices such that no two distinct vertices in the set are directly connected by an edge in the tree. A maximum independent set is an independent set that contains the largest possible number of vertices.

Given a forest of $k$ trees, we want to add $k-1$ edges to unite the forest into a single tree so as to maximize the size of the maximum independent set of the resulting tree. Please find the additional edges.

If there are several valid answers, you may output any of them.

#### **Input**

Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 10^4$). The description of the test cases follows.

The first line of each test case contains a single integer $k$ ($2 \le k \le 2 \cdot 10^5$) — the number of trees in the forest.

This is followed by a description of each of the $k$ trees, which are numbered $1, 2, \ldots, k$ in order:

The first line contains a single integer $n$ ($1\le n \le 2 \cdot 10^5$) — the size of the tree. The vertices of the tree are numbered with integers from $1$ to $n$.

Each of the next $n-1$ lines contains two integers $u$ and $v$ ($1 \le u,v \le n$, $u \ne v$), denoting an edge between vertices $u$ and $v$. It is guaranteed that the given edges form a tree.

It is guaranteed that the sum of $k$ over all test cases does not exceed $2 \cdot 10^5$.

It is guaranteed that the sum of $n$ over all test cases does not exceed $2 \cdot 10^5$.

#### **Output**

For each test case, output $k-1$ lines; each line contains four integers $t_1, v_1, t_2, v_2$, denoting an edge between $(t_1,v_1)$ and $(t_2,v_2)$ that is added to the original graph.

Note that we number all $k$ trees from $1$ to $k$ in the order in which they appear in the input data. For any tree $i$ ($1\le i \le k$), if it contains $n$ nodes, then its nodes are numbered from $1$ to $n$. The $j$\-th node in this tree is denoted by $(i,j)$.

#### **Example**

Input

```
2
2
1
1
2
3
1 2
1 3
1
```

Output

```
2 1 1 1
2 1 1 1
```

#### **Note**

In the first test case, the graph has two vertices and no edge; adding an edge between these two nodes is the only way to turn the graph into a tree.

In the second test case, we can add an edge between the only vertex $1$ of tree $2$ and one of the vertices $1$, $2$, and $3$ of tree $1$.

-   add edge $(2,1)-(1,1)$, the size of a maximum independent set of the resulting tree is 3.
-   add edge $(2,1)-(1,2)$, the size of a maximum independent set of the resulting tree is 2.
-   add edge $(2,1)-(1,3)$, the size of a maximum independent set of the resulting tree is 2.

So, we choose the edge $(2,1)-(1,1)$ since it is optimal.



## Sol

树形DP计算出每棵树的最大独立集，并标记哪些点是在最大独立集中的哪些点不再。

找出一个未选中点，其他树都向这个点连边即可得到合法构造。

有一种特殊情况，若所有树都是独根树，不存在未选中点，此时的构造方案是星状树。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 2e5 + 5;
struct edge {
    int to, nxt;
} e[N * 2];
int head[N], tot;
int k, n[N], sum[N], root[N];
void add(int id, int u, int v) {
    u += sum[id - 1];
    v += sum[id - 1];
    e[++ tot] = {v, head[u]};
    head[u] = tot;
}
int down[N][2];
bool c[2][N]; // 父亲不选/选时，自己选不选
void dfs1(int u, int f) {
    down[u][0] = 0, down[u][1] = 1;
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == f) continue;
        dfs1(v, u);
        if (down[v][0] > down[v][1]) down[u][0] += down[v][0], c[0][v] = 0;
        else                         down[u][0] += down[v][1], c[0][v] = 1;
        down[u][1] += down[v][0];
        c[1][v] = 0;
    }
}
bool x[N]; // 每个点是否被选中
void dfs2(int u, int f) {
    if (!f) x[u] = down[u][1] > down[u][0];
    else x[u] = c[x[f]][u];
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == f) continue;
        dfs2(v, u);
    }
}
void solve() {
    tot = 0;
    memset(head, 0, sizeof head);
    cin >> k;
    bool f = 1;
    for (int i = 1; i <= k; i++) {
        cin >> n[i];
        if (n[i] > 1) f = 0;
        sum[i] = sum[i - 1] + n[i];
        for (int j = 1; j < n[i]; j++) {
            int u, v;
            cin >> u >> v;
            add(i, u, v);
            add(i, v, u);
        }
        root[i] = sum[i - 1] + 1;
        dfs1(root[i], 0);
        dfs2(root[i], 0);
    }
    // 全是独根树
    if (f) {
        for (int i = 2; i <= k; i++) {
            cout << "1 1 " << i << " 1\n";
        }
        return;
    }
    int ai, aj;
    for (int i = 1; i <= k; i++) {
        for (int j = 1; j <= n[i]; j++) {
            if (x[sum[i - 1] + j] == 0) {
                ai = i, aj = j;
                break;
            }
        }
    }
    for (int i = 1; i <= k; i++) {
        if (i == ai) continue;
        cout << ai << " " << aj << " " << i << " " << 1 << endl;
    }
}
int main() {
    int t;
    cin >> t;
    while (t --) solve();
    return 0;
}
```

# E. Memory Cell Interception

time limit per test: 2 seconds

memory limit per test: 256 megabytes

input: standard input

output: standard output

There are two threads, $\texttt{A}$ and $\texttt{B}$, and one shared memory cell. Initially, the memory cell contains $0$.

Thread $\texttt{A}$ has a fixed command sequence $s$ of length $n$, and thread $\texttt{B}$ has a fixed command sequence $t$ of length $m$. Each command is either $\texttt{READ}$, denoted by $\texttt{R}$, or $\texttt{WRITE}$, denoted by $\texttt{W}$.

The commands of each thread must be executed in their original order. However, commands from the two threads may be interleaved arbitrarily. In other words, the actual execution is a global sequence of $n+m$ commands obtained by merging $s$ and $t$ while preserving the order of commands inside each string.

For example, suppose $s=$ $\texttt{RWW}$ and $t=$ $\texttt{WR}$.

-   The sequence  $ s_1,t_1,s_2,t_2,s_3 $ is a valid interleaving. The corresponding global command sequence is $\texttt{RWWRW}$.

-   The sequence  $ s_2,t_1,s_1,t_2,s_3 $ is not a valid interleaving, because the commands of $s$ are not executed in their original order.

-   The sequence  $ s_1,t_1,s_2,t_2 $ is not a valid interleaving, because it does not execute all commands.

The global execution has timestamps. Before any command is executed, the timestamp is $0$. The command executed at position $i$ in the global sequence has timestamp $i$.

-   When a $\texttt{WRITE}$ command is executed at timestamp $i$, it writes the value $i$ into the shared memory cell.
-   When a $\texttt{READ}$ command is executed, it reads the current timestamp value stored in the shared memory cell.

For every $\texttt{READ}$ command appearing in either $s$ or $t$, determine how many distinct values it can read over all valid interleavings of the two command sequences.

#### **Input**

Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 10^4$). The description of the test cases follows.

The first line of each test case contains two integers $n$ and $m$ ($1 \le n,m \le 2 \cdot 10^5$) — the lengths of the command sequences of threads $\texttt{A}$ and $\texttt{B}$, respectively.

The second line contains a string $s$ of length $n$ — the command sequence of thread $\texttt{A}$.

The third line contains a string $t$ of length $m$ — the command sequence of thread $\texttt{B}$.

Each character of $s$ and $t$ is either $\texttt{R}$ or $\texttt{W}$. Each of the strings $s$ and $t$ contains at least one character $\texttt{R}$.

It is guaranteed that the sum of all $n$ over all test cases does not exceed $2 \cdot 10^5$, and the sum of all $m$ over all test cases does not exceed $2 \cdot 10^5$.

#### **Output**

For each test case, print two lines.

The first line contains a sequence of integers, representing the answer for each $\texttt{READ}$ instruction appearing in $s$ in order. The length of the sequence must equal the number of letters $\texttt{R}$ in $s$.

The second line contains a sequence of integers, representing the answer for each $\texttt{READ}$ instruction appearing in $t$ in order. The length of the sequence must equal the number of letters $\texttt{R}$ in $t$.

#### **Example**

Input

```
3
1 1
R
R
1 2
R
WR
3 3
WRW
RWR
```

Output

```
1
1
2
2
4
3 4
```

#### **Note**

In the first example, both $\texttt{R}$ commands can only get the value $0$ initially set in the cell, so the answers are both $1$.

In the second example, there are $3$ different interleavings (the red letter $\texttt{R}$ represents the one in $s$):

-   $\mathtt{\color{red}{R}WR}$: the first $\texttt{R}$ reads $0$, the second $\texttt{R}$ reads $2$;
-   $\mathtt{W\color{red}{R}R}$: the first $\texttt{R}$ reads $1$, the second $\texttt{R}$ reads $1$;
-   $\mathtt{WR\color{red}{R}}$: the first $\texttt{R}$ reads $1$, the second $\texttt{R}$ reads $1$;

Above all, both $\texttt{R}$ commands might see $2$ distinct values.

## Sol
考虑 `s` 串的答案，记当前 `R` 的位置为 `cur`，最近一个 `W` 的位置为 `lst`，则它可以从该 `W` 读取到的时间戳范围为：$[lst,lst+m]$。
考虑不从这个 `W` 读取，而是把 `t` 串中的 `w` 插入到 $[lst,cur-1]$ 这一段，记 `t` 串中最后一个 `W` 的位置为 `lst_t`，则从 `t` 串中读取最大时间戳为 `cur-1+lst_t`，两个上限取最小值即可。
有两个特殊情况：
- `t` 串没有 `W`，则不考虑从 `t` 串中读取。
- `cur` 之前没有 `W`，此时只能从 `t` 串中读取，此处比较麻烦，后面展开说。

当 `s` 串中第一个字符就是 `R` 时，它能读取的时间戳为 $0$ 和 `t` 串中所有 `W` 的下标；

当 `s` 串中第二个字符是 `R` 时，它能读取的时间戳为 $0$ 和 `t` 串中所有 `W` 的下标，还有 `W` 的下标加一；

当 `s` 串中第三个字符是 `R` 时，它能读取的时间戳为 $0$ 和 `t` 串中所有 `W` 的下标，还有 `W` 的下标加一，还有下标加二；

依次类推，可以用前缀和来解决。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N  = 4e5 + 5;
int ans1[N], ans2[N];
void solve() {
    memset(ans1, 0, sizeof ans1);
    memset(ans2, 0, sizeof ans2);
    ans1[0] = ans2[0] = 1;
    int n, m;
    string s, t;
    int lst_s = 0, lst_t = 0;
    cin >> n >> m >> s >> t;
    s = ' ' + s;
    t = ' ' + t;
    int cur = -1;
    for (int i = 1; i <= n + m; i++) {
        if (i <= n && s[i] == 'W') {
            lst_s = i;
            cur = 1;
        } else if (~ cur) {
            cur ++;
        }
        if (~ cur) ans1[cur] ++;
    }
    for (int i = 1; i <= m; i++) {
        ans1[i] += ans1[i - 1];
        // cout << ans1[i] << " ";
    }
    cur = -1;
    for (int i = 1; i <= n + m; i++) {
        if (i <= m && t[i] == 'W') {
            lst_t = i;
            cur = 1;
        } else if (~ cur) {
            cur ++;
        }
        if (~ cur) ans2[cur] ++;
    }
    for (int i = 1; i <= n; i++) {
        ans2[i] += ans2[i - 1];
        // cout << ans2[i] << " ";
    }
    int lst_w = 0;
    for (int i = 1; i <= n; i++) {
        if (s[i] == 'W') lst_w = i;
        else if (lst_w == 0) {
            cout << ans2[i] << " ";
        } else {
            cout << max(lst_w + m, lst_t?(i - 1 + lst_t):0) - lst_w + 1 << " ";
        }
    }
    cout << endl;
    lst_w = 0;
    for (int i = 1; i <= m; i++) {
        if (t[i] == 'W') lst_w = i;
        else if (lst_w == 0) {
            cout << ans1[i] << " ";
        } else {
            cout << max(lst_w + n, lst_s?(i - 1 + lst_s):0) - lst_w + 1 << " ";
        }
    }
    cout << endl;
}
int main() {
    int t;
    cin >> t;
    while (t--)
        solve();
    return 0;
}
```

# F. Tree Reduction Game

time limit per test: 2 seconds

memory limit per test: 512 megabytes

input: standard input

output: standard output

Alice and Bob are playing a game on a tree with $n$ vertices. Alice moves first, and then they take turns.

At any moment, the tree has a designated root. Suppose the current root is $u$. On their turn, the current player must choose a child $v$ of $u$ and perform exactly one of the following operations:

1.  Make $v$ the new root.
2.  Delete the entire subtree$^{\text{∗}}$ rooted at $v$.

Here, parent-child relationships are determined with respect to the current root.

During the entire game, each vertex can become the root **at most once**.

If a player has no valid move on their turn, that player loses.

Before the game begins, as compensation for moving second, Bob may choose any vertex as the initial root.

Given the tree, determine the winner assuming both players play optimally. If Bob can win, output all vertices that he can choose as the initial root to guarantee a victory, **in increasing order**.

$^{\text{∗}}$The subtree rooted at vertex $v$ is the set of all vertices that pass through $v$ on a simple path to the root (including $v$ itself).

#### **Input**

Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 10^4$). The description of the test cases follows.

The first line of each test case contains a single integer $n$ ($2 \le n \le 5 \cdot 10^5$), the number of vertices in the tree.

Each of the next $n-1$ lines contains two integers $u$ and $v$ ($1 \le u,v \le n$, $u \ne v$), denoting an edge between vertices $u$ and $v$. It is guaranteed that the given graph is a tree.

It is guaranteed that the sum of $n$ over all test cases does not exceed $5 \cdot 10^5$.

#### **Output**

-   If Alice wins, print `Alice`.
-   Otherwise, print `Bob` on the first line. On the second line, print an integer $k$, the number of vertices that Bob can choose as the initial root to guarantee his victory. On the third line, print $k$ distinct integers $v_1,v_2,\ldots,v_k$ **in increasing order**, denoting all such vertices.

**Note**

In the first test case, regardless of which vertex Bob chooses as the initial root, Alice can remove the only child subtree on her first move. Bob then has no legal move, so Alice wins.

In the fifth test case, vertices $2$, $4$, and $6$ are winning choices for Bob. We explain vertex $2$; the other two cases are symmetric.

If Bob chooses vertex $2$ as the initial root, its children are $1$ and $3$.

-   If Alice changes the root from $2$ to $1$, Bob can change the root from $1$ to $4$ (or $6$).
-   If Alice deletes the subtree rooted at $1$, Bob deletes the subtree rooted at $3$, leaving Alice with no legal move.
-   If Alice changes the root from $2$ to $3$, Bob deletes the subtree rooted at $2$, again leaving Alice with no legal move.
-   If Alice deletes the subtree rooted at $3$, Bob deletes the subtree rooted at $1$.

Thus Bob can force a win when the initial root is $2$. By symmetry, the same holds for $4$ and $6$. If Bob chooses any of $1$, $3$, $5$, or $7$, Alice has a winning strategy. Therefore the answer is $2,4,6$.

## Sol
考虑一个点必败/必胜的条件。

若 $u$ 点从 $v$ 点走到，下一步它可以选择走到除 $v$ 以外的相邻点，也可能删除任意一个相邻点：
- 若一个可走到的相邻点是必败点，那么 $u$ 点之间走过去即可，$u$ 点就是必胜点。
- 若所有可走到的相邻点都是必胜点，那么不能走过，只能选择删除其中一个，双方都只能选择做删除操作，当 $deg[u]$ 为奇数时，先手可以做最后依次删除，$u$ 必胜，否则后手做最后的删除，$u$ 必败。

对于树上任意一点 $u$，它会被 Bob 选作根的充要条件是它的相邻点从 $u$ 走到都是胜的，且 $deg[u]$ 为偶数，可以发现，需要计算两个信息：每条边上向上走后终点必胜/必败，向下走后终点必胜/必败。

详情看注释。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 5e5 + 5;
struct edge {
    int to, nxt;
} e[2 * N];
int head[N], tot;
void add(int u, int v) {
    e[++ tot] = {v, head[u]};
    head[u] = tot;
}
int n;
/*
down[u] ： 父亲走到自己后，自己能否必胜
up[u] ： 自己走到父亲后，父亲是否必胜

一个点 u，从 v 走到，想要必胜，当且仅当：
1. u 点能走到的所有点中存在必败点，
2. 若 u 能走到点都是必胜点，deg[u] 为奇数

即，当 u 能走到的所有点都必胜且 deg[u] 为偶数时，u 点必败

特别得，无视根节点的 up 值。
*/
bool down[N], up[N];
int deg[N], fa[N];
void dfs1(int u, int f) {
    fa[u] = f;
    bool win = 1;
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == f) {
            continue;
        }
        dfs1(v, u);
        if (!down[v]) win = 0;
    }
    if (win && deg[u] % 2 == 0) down[u] = 0;
    else down[u] = 1;
}
void dfs2(int u, int f) {
    int win_cnt = 0;
    if (f) win_cnt += up[u];
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == f) {
            continue;
        }
        win_cnt += down[v];
    }
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (v == f) {
            continue;
        }
        if (win_cnt - down[v] == deg[u] - 1 && deg[u] % 2 == 0) up[v] = 0;
        else up[v] = 1;
        dfs2(v, u);
    }
}
void solve() {
    tot = 0;
    for (int i = 1; i <= n; i++) deg[i] = head[i] = 0;
    cin >> n;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        add(u, v);
        add(v, u);
        deg[u] ++;
        deg[v] ++;
    }
    dfs1(1, 0);
    dfs2(1, 0);
    vector<int> ans;
    // bob 只选必败点：即 cnt_win = deg，且 deg 为偶数
    for (int u = 1; u <= n; u++) {
        int cnt_win = 0;
        for (int i = head[u]; i; i = e[i].nxt) {
            int v = e[i].to;
            if (v == fa[u] && v) {
                cnt_win += up[u];
            } else {
                cnt_win += down[v];
            }
        }
        if (cnt_win == deg[u] && deg[u] % 2 == 0) ans.push_back(u);
    }
    if (ans.size()) {
        cout << "Bob\n";
        cout << ans.size() << endl;
        for (int i = 0; i < ans.size(); i++) cout << ans[i] << " ";
        cout << endl;
    } else {
        cout << "Alice\n";
    }
}
int main() {
    int t;
    cin >> t;
    while (t --) solve();
	return 0;
}
```
